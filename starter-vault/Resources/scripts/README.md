# Scripts

Every script you write in the course lands here, starting with Module 2.

Keeping them in the vault rather than scattered across your Desktop is
deliberate. They get version controlled along with your notes, they
travel to any machine you clone the vault onto, and the note explaining
why you wrote one sits a folder away from the script itself.

Expected arrivals:

| Script | From | What it does |
| --- | --- | --- |
| `machine-report.ps1` | Lesson 2.1 | Measures a Windows machine and writes a Markdown report into `Resources/` |
| `failed-logins.sh` | Lesson 2.2 | Ranks source addresses by failed SSH login attempts |
| `move-fsmo.ps1` | Lesson 5.10 | Reports on, and optionally moves, Active Directory FSMO roles |

This file only exists to keep the folder here. Git does not track empty
folders, so without a file inside, this directory would not survive the
download. You can delete it once you have scripts of your own, though it
is a reasonable place to keep an index of them.
