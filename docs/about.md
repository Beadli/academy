# About

Beadli Lab Academy is built and maintained by Steve — an infrastructure and
security engineer who runs the real enterprise-grade home lab this
curriculum is modeled on: Active Directory across multiple domain
controllers, a two-tier PKI with an offline root, AD FS single sign-on,
Wazuh SIEM with a custom detection-tiering framework, Suricata, OpenVAS,
Ansible automation across Windows and Linux, and more.

Everything taught here has been built, broken, monitored, attacked, and
fixed in that lab first. The war stories in the modules are real.
